# JavaScript e estudos

Este repositório reúne aulas, exercícios e materiais de estudo de JavaScript, com uma estrutura organizada para facilitar a navegação.

## Estrutura do projeto

- [AULAS.md](https://github.com/NicollasRodrigo/estudos-javascript/blob/main/estudos-javascript/AULAS.md) — índice das trilhas de estudo.
- [Estudos JavaScript](https://github.com/NicollasRodrigo/estudos-javascript/blob/main/estudos-javascript/AULAS.md) — acesse cada aula separadamente (índice completo por aula dentro da pasta).
- [estudos-javascript](https://github.com/NicollasRodrigo/estudos-javascript/tree/main/estudos-javascript) — cópia complementar das aulas organizadas em subpastas.
- [guia-javascript](https://github.com/NicollasRodrigo/estudos-javascript/blob/main/guia-javascript/README.md) — material de apoio e referências.
- [Exercicios](https://github.com/NicollasRodrigo/estudos-javascript/tree/main/Exercicios) — índice e trilhas futuras.
- [Java](./Java/) — conteúdo separado para estudos em Java.

## Como navegar

- Comece por [AULAS.md](https://github.com/NicollasRodrigo/estudos-javascript/blob/main/estudos-javascript/AULAS.md) para acompanhar a sequência das aulas.
- Use [Exercicios/00-indice.md](https://github.com/NicollasRodrigo/estudos-javascript/blob/main/Exercicios/00-indice.md) para acessar a organização dos exercícios.
- Consulte [Java/README.md](./Java/README.md) para a seção dedicada ao Java.
