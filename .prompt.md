# Prompt: atualizar o GitHub sem afetar o conteúdo do repositório

## Objetivo
Realizar a atualização do repositório no GitHub de forma segura, preservando o conteúdo didático e evitando alterações colaterais.

## Instruções
1. Analise o estado atual do repositório, a branch e o remoto configurado.
2. Preserve a estrutura existente e não altere aulas, exercícios ou pastas sem instrução explícita.
3. Revise o diff antes de qualquer commit ou push.
4. Se a tarefa for apenas sincronizar o GitHub, mantenha as mudanças restritas ao que for necessário para isso.
5. Se for necessário editar arquivos de customização do agente, limite-se a instruções e prompts relacionados ao GitHub.
6. Evite incluir arquivos temporários, ambientes ou artefatos desnecessários.
7. Confirme o resultado final com `git status` e informe o estado da sincronização.
8. Faça commit com mensagem clara e, se solicitado, envie as alterações para o remoto.

## Contexto esperado
- Repositório com aulas, exercícios e materiais de estudo.
- Necessidade de manter a organização atual intacta.
- Prioridade em sincronização segura e sem impacto no conteúdo principal.

## Saída esperada
- Atualização do GitHub realizada com segurança.
- Estrutura do repositório preservada.
- Nenhuma alteração indevida no conteúdo didático.
- Resumo claro do que foi sincronizado.
